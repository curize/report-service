# Changelog

## 1.0.1
- Порт приложения читается из переменной окружения PORT (по умолчанию 8080); код менять для смены порта не нужно.
- Добавлены healthcheck (healthcheck.py, HEALTHCHECK), compose.yaml с параметрами из env, env.example.
- Ограничение размера журналов контейнера (5 МБ x 3 файла).
- Новое сопоставление портов: хост 8207 -> контейнер 8207 (раньше 8090 -> 8080).
- Добавлены скрипты scripts/acceptance.py и scripts/verify_backup.py, документы паспорта, runbook и чек-листа.
