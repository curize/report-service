# Паспорт приложения и целевой платформы

## Приложение
| Параметр | Значение |
|---|---|
| Название | report-service |
| Назначение | HTTP-сервис: принимает записи {"name", "value"} и строит сводный отчёт (количество, сумма, среднее, максимум) |
| Пользователи | студент-разработчик, преподаватель (проверка) |
| Входы | POST /records (JSON), переменные окружения PORT, DATA_DIR |
| Выходы | JSON-ответы GET /health, /report, /records; журнал в stdout контейнера |
| Состав версии | report.py, server.py, healthcheck.py, Dockerfile, compose.yaml, env.example, CHANGELOG.md, README.md |
| Зависимые компоненты | Python 3.12.7 (образ python:3.12.7-slim), сторонних библиотек нет |
| Данные | data.json в именованном томе report-data (/data) |
| Версия выпуска | v1.0.1 (предыдущая v1.0.0) |

## Критерии приёмки
1. GET /health возвращает 200 и status=ok.
2. Запись создаётся (201) и читается обратно.
3. Некорректная запись отклоняется (400), неизвестный маршрут даёт 404.
4. Новый порт отвечает, старый порт закрыт.
5. Данные предыдущей версии сохранены после замены.
6. Контейнер получает статус healthy.

## Целевая платформа (вариант 7: порт по умолчанию занят)
| Параметр | Значение |
|---|---|
| Узел | учебный компьютер студента (заполнить: модель/ОС) |
| Архитектура | x86-64 (проверить: docker version) |
| Контейнерный движок | Docker с Compose v2 |
| Порт по умолчанию | 8080 — занят другим процессом на сервере |
| Выбранный порт | 8207 (хост и контейнер), задаётся через PORT без изменения кода |
| Старое сопоставление | v1.0.0: хост 8090 -> контейнер 8080 |
| Данные | том report-data -> /data |
| Журналы | json-file, 5 МБ x 3 файла |
